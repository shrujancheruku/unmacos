UnMacOS vs AeroSpace, yabai, Amethyst and Rectangle

AeroSpace, yabai and Amethyst are tiling window managers, and Rectangle snaps windows into place. They each do one job well. UnMacOS is a whole desktop: it includes a tiling window manager (Rift) and sets up the bar, launcher, menus, terminal apps and colours around it.

Pick a window manager if…

…you already have a bar, launcher and colours you like and only want windows to tile. AeroSpace is a good choice if you know i3, yabai if you want binary space partitioning and deep scripting, and Amethyst if you'd rather configure it in a window. Rectangle suits you if you only want to snap windows to halves and corners.

Pick UnMacOS if…

…you want the whole keyboard-first desktop without assembling it: tiling, a status bar, an app launcher, clipboard and emoji menus, terminal apps on their own keys, and one theme that reaches every app, working together on day one. It's plain dotfiles underneath, so you can change any of it.
