Install · about 15 minutes on a new Mac

Install UnMacOS

You need a Mac with Apple silicon on macOS 15 Sequoia or later (macOS 26 Tahoe and 27 included). Open Terminal and run:

{{INSTALL_CMD}}

UnMacOS writes the config files it manages (Rift, SketchyBar, Ghostty, tmux, Neovim and others). If you already have your own, back up ~/.config first. You can read install.sh before running it.

What happens

  1. The installer

    It asks for your password once, then installs Homebrew (with Apple's command line tools), chezmoi and the UnMacOS files, then asks one thing: Install with defaults or Customise. It's safe to run again if anything is interrupted.

    Install with defaults asks nothing else. After your password, all that is left is the checklist below. Customise starts the setup wizard. With no terminal (a script, say) or with UNMACOS_SETUP=<file> (see "The same setup on another Mac" below) the installer never asks: it takes the defaults, or that file's answers.

  2. The setup wizard (Customise)

    unmacos-setup asks what you want before anything changes. Arrow keys move, x or Tab ticks and unticks, Enter goes on. Every question has a sensible default.

    QuestionWhat it's for
    Git name and emailYour ~/.gitconfig. Stays on your Mac. Optional: UnMacOS uses the ones git config --global already has, and if there are none, leaves them out and lists setting them in the checklist
    1Password?Reads secrets (the Spotify player's client ID) from 1Password. No is fine
    ThemeAny of the {{THEME_COUNT}}. Switch later with Alt + Ctrl + Shift + Space
    Extra appsOptional groups: developer tools, everyday apps, music and video, games, App Store. Untick single apps inside a group
    What UnMacOS changesApple Intelligence and Liquid Glass off, wallpaper, macOS accent colours, and theming for Firefox, Spotify and Orca. Untick anything you want left alone
    Windows and pointerAnimations, focus follows mouse, pointer jumps to the focused window and hides
    WeatherThe place for the bar's weather, or auto to use your IP

    Your answers are saved to ~/.config/unmacos/setup.toml. Run unmacos-setup again any time to change them.

    Every question, its default and what it changes: the settings reference.

  3. A few clicks macOS won't let a script make

    The installer finishes with a checklist and shows which steps it can see are done. unmacos-setup --checklist shows it again and opens the right System Settings page.

    • Privacy & Security → Accessibility: turn on rift and clipse, then run rift service restart. This lets Rift move windows. No SIP changes needed.
    • Log out and back in once.
    • The first menu you open makes Ghostty ask to run a command: allow it.
    • On macOS 26 and later, approve UnMacOS: no Apple Intelligence in General → Device Management (skipped if you kept Apple Intelligence).
    • Run spotify_player once to log in to Spotify, if you use it.
    • In Firefox, click Pywalfox → Fetch Pywal colors once.

  4. Check it

    unmacos-doctor

    It checks services, permissions, theme, fonts and menus, and tells you what to fix. When it says All good, press Alt + Space and you're in.

The same setup on another Mac

Export your answers, with today's theme and weather place, and hand them to the installer on the new Mac. It then asks no questions. The file has your git name and email in it, so keep it somewhere private.

unmacos-setup --export ~/setup.toml   # on this Mac

# on the new Mac, with that file copied over:
UNMACOS_SETUP=~/setup.toml bash -c "$(curl -fsSL \
  https://raw.githubusercontent.com/shrujancheruku/unmacos/main/install.sh)"

Updating

Pick Update in the menu, or run chezmoi git pull -- --ff-only && unmacos-setup --yes. It keeps your saved answers and asks nothing. Release notes for each version are on GitHub Releases.

Leaving things alone

Everything UnMacOS changes outside its own apps can be switched off in unmacos-setup, or for a single run with a variable such as UNMACOS_KEEP_AI=1 chezmoi apply. The README lists how to undo each one.
