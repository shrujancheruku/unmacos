One theme across your whole Mac

Pick a theme and SketchyBar, the window borders, Ghostty, tmux, btop, Neovim, Firefox, Spotify and Orca change together, along with the wallpaper and macOS's accent colour. Apps that are already open switch too. Press Alt + Ctrl + Shift + Space to open the picker.

Every card below has a button that themes this page, so you can try a palette before you install anything.

Make your own

Each theme is one colors.toml in ~/.local/share/unmacos/themes/<name>/, in Omarchy's format, so Omarchy themes drop straight in. Copy one, change the colours, and pick it from the menu or run unmacos-theme-render <name>.

A theme can also ship its own app config, such as a hand-tuned ghostty.conf, to replace the generated one. Wallpapers go in ~/.config/unmacos/backgrounds/<theme>/.

Tokyo Night is UnMacOS's own hand-tuned palette; the others come from Omarchy (MIT), whose wallpapers each theme downloads on first use.
